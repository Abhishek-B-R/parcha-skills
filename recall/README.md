# Recall skill

Agent instructions for using a separately installed Recall system from Claude Code,
Codex, or pi. This package contains the skill and plugin manifests. The implementation,
installers, and deployment configuration are maintained separately and are not included.

Install the skill through [skills.sh](https://skills.sh/Parcha-ai/parcha-skills/recall):

```bash
npx skills add Parcha-ai/parcha-skills --skill recall
```

Installing this skill does not install or start the Recall system. Use your
organization's private setup instructions to provision it before running commands.
See [the skill](skills/recall/SKILL.md) for usage.
