# Tether skill

Agent instructions for using a separately installed Tether system from Claude Code,
Codex, or pi. This package contains the skill and plugin manifests. The implementation,
installers, and deployment configuration are maintained separately and are not included.

Install the skill through [skills.sh](https://skills.sh/Parcha-ai/parcha-skills/tether):

```bash
npx skills add Parcha-ai/parcha-skills --skill tether
```

Installing this skill does not install or start the Tether system. Use your
organization's private setup instructions to provision it before running commands.
See [the skill](skills/tether/SKILL.md) for usage.
